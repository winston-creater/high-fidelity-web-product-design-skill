# Prompt: Handoff Report

## Goal

Create a final handoff report for designers, engineers, and product owners.

## Output

```text
outputs/08-handoff/handoff-report.md
```

## Include

- project summary
- final page strategy
- references analyzed
- decisions made
- canonical artifacts generated
- render artifacts generated
- Figma status
- frontend status
- QA score summary
- assumptions
- unresolved risks
- next steps
- upload/package notes

## Important

Be honest about tools that were unavailable or steps that were only prepared as contracts/prompts.
