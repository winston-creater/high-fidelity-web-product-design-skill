# Prompt: Reference To Own Idea Comparison

## Goal

Compare reference findings with the user's own idea.

## Output

Create `outputs/02-reference-analysis/reference-comparison-matrix.md`:

```md
# Reference Comparison Matrix

| Own idea / hypothesis | Reference evidence | Decision | Implementation adaptation | Reason |
|---|---|---|---|---|

## Validated ideas

## Ideas to modify

## New ideas to add

## Patterns to reject

## Open questions
```

## Decision values

Use one of:

- keep
- modify
- reject
- add
- defer

Every decision must explain why it is appropriate for the user's project.
