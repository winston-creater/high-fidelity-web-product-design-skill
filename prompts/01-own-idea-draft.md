# Prompt: Own Idea Draft

## Goal

Generate the first website direction based only on the user's own ideas, before analyzing reference websites.

## Rules

- Do not use reference website patterns yet.
- Preserve the user's business goal.
- Make section decisions testable.
- Keep it simple enough to validate.

## Output

Create `outputs/01-own-idea/own-idea-draft.md`:

```md
# Own Idea Draft

## Product hypothesis

## Audience and conversion goal

## Initial page structure

| Order | Section | Purpose | Content | CTA / Interaction | Risk |
|---|---|---|---|---|---|

## Initial UI direction

## Initial interaction direction

## Initial responsive assumptions

## Questions reference websites should help answer
```
