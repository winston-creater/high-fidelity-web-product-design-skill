# Prompt: Own Idea Critique

## Goal

Critique the initial idea before reference analysis.

## Analyze

- clarity of value proposition
- section order
- trust and proof
- CTA strength
- information density
- interaction complexity
- mobile viability
- accessibility risks
- implementation risk

Create `outputs/01-own-idea/own-idea-critique.md`:
