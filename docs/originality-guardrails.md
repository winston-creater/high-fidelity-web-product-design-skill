# Originality Guardrails

This Skill is for pattern analysis and original synthesis, not copying.

## Allowed

You may adapt:

- section order patterns
- information architecture patterns
- CTA strategy
- component categories
- interaction patterns
- responsive strategy
- general layout principles
- general tone and density

## Not allowed

Do not copy:

- logos
- product screenshots
- proprietary illustrations
- icon sets
- brand colors as a unique identity combination
- exact visual composition
- proprietary wording
- testimonials or customer logos
- protected media assets

## Transform before using

Every reference-inspired idea should be transformed:

```text
reference observation → abstract pattern → user-specific original implementation
```

Example:

```text
Reference: hero with large dashboard screenshot and two CTAs.
Pattern: visual proof plus direct conversion path.
Original implementation: custom product mockup, user-specific headline, one primary CTA and one trust-supporting secondary action.
```
